📋 タスク連携ツール ヘルプ

毎朝 5:00 に、スプレッドシートに登録された曜日別タスクを Notion データベースへ自動投入します。

1. セットアップ手順

  1. Notion で Integration を作成 → Internal Integration Token (secret_...) を取得。
    (https://www.notion.so/my-integrations)
  2. 送信先の Notion データベースを開き、右上の … → + Add connections から上記 Integration を追加。
  3. データベース URL から Database ID を取得 (URL の ? 以前の最後の 32 桁)。
  4. サイドバーの「2. Notion 認証情報」で Integration Key と Database ID を入力 →「保存」→「接続テスト」で OK が出ることを確認。
  5. 「3. 初期設定」を 1 回だけ実行 (シート 2 枚 + ログシートを生成)。
  6. 「4. トリガー」で 毎朝5時トリガーを有効化。
  7. 必要に応じて「5. 手動実行」でテスト送信。

2. シート構成

2-1. タスクマスタ シート

毎日 (曜日ごと) に送りたいタスクを 1 行 1 タスクで記入します。

列内容備考
曜日月 / 火 / 水 / 木 / 金 / 土 / 日必須・データ入力規則あり
タスク名Notion ページのタイトル必須
カテゴリ任意の分類Notion 側で Select 型推奨
優先度高 / 中 / 低データ入力規則あり
備考補足テキスト長文可
有効チェックON のみ送信対象OFF にすると一時停止できる

2-2. 設定 シート (マッピング)

「スプレッドシートのどの列を、Notion のどのプロパティに、どの型で送るか」を定義します。
Notion 側のプロパティ名や型を変更したら、このシートを編集してください。

3. Notion データベースの初期構造

初期想定では以下のプロパティを Notion 側に作成しておきます。

プロパティ名型

4. データベース構造を変更したい時

  1. Notion 側でプロパティを追加 / 名称変更 / 型変更を行う。
  2. スプレッドシートの タスクマスタ シートに必要な列を追加 (列ヘッダ名は自由)。
  3. 設定 シートに シート列名 / Notionプロパティ名 / 型 の対応行を追加または更新。
  4. サイドバーから「接続テスト」で Notion 側プロパティ一覧と照合。
  5. 「手動実行」で 1 度送ってみて、エラーが出ないか確認。

5. 対応している Notion プロパティ型

型 (設定シートに記入)変換ルール

6. よくあるトラブル

症状対処
401 UnauthorizedIntegration Key が誤っているか、Notion DB に Integration が接続されていない。
404 / object_not_foundDatabase ID が誤っている。または Integration が DB にアクセス権を持っていない。
property does not exist設定 シートの「Notionプロパティ名」と実際の DB のプロパティ名が一致していない。
選択肢が作成されないNotion 側で対象 Select プロパティの「Allow new options」を ON にするか、選択肢を事前定義する。
トリガーが動かないサイドバー「4. トリガー」で再有効化。実行履歴は GAS の「実行数」画面で確認。
メモ: Notion API のレートリミット (3req/sec) を考慮して、1 件送信ごとに 350ms スリープしています。 大量タスク (50 件以上) を一度に送ると、GAS の 6 分制限に近づく可能性があるので、必要なら分割してください。

7. ログ

送信結果は ログ シートに自動追記されます (日時 / 対象曜日 / 成功件数 / 失敗件数 / 詳細)。
